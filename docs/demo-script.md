# Three-minute demo script

1. Start RAG and API; open `http://127.0.0.1:8000/`.
2. Upload `examples/demo_sensor.md` and point out the live Agent graph.
3. Open mechanism paths and distinguish accepted/unresolved/rejected branches.
4. Show Critic decision, prompt/model versions, trace spans, and token usage.
5. If gated, revise or approve; resume from the same checkpoint.
6. Open the final report, ask an evidence question, and inspect citations.
7. Record a physical verification result, rerun, and show its effect on case rank.
8. Compare two runs while clearly separating smoke/operational metrics from
   expert-reviewed benchmark accuracy.
